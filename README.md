# NRSK — Plant Engineering & Project Advisory

A responsive, professional one-page corporate website for NRSK.

## Files
- `index.html` — complete website structure/content
- `styles.css` — responsive visual system and layout
- `script.js` — navigation and reveal animations
- `assets/website-concept.png` — generated visual concept used by the site

## Run locally
Open `index.html` in a browser.

For the best experience, run a simple local server from this folder:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Before launch
1. Replace `contact@nrskadvisory.com` with the company's actual email.
2. Replace the temporary/generated imagery with licensed project/plant photographs.
3. Add the final names, bios and credentials of the four NRSK members.
4. Independently verify the market examples and numbers before publishing.
5. Add a privacy policy, terms and any required statutory/company details.
6. The website now presents NRSK as an All-India advisory firm and includes the 3–5 day technical assessment offer and ~13 lakh MT indicative installed FCB capacity.
